SKM DÉLIVRANCE V1.1
=====================
Prototype web mobile autonome avec boutons actifs.

Fonctions:
- 30 questions / 8 catégories
- précédent / sauvegarde / reprise
- résultats calculés
- partage du résultat
- téléchargement du bilan en fichier texte
- prière personnalisée
- copie et partage de la prière
- parcours 7 jours avec jours cochables
- journal local enregistrable/effaçable
- réinitialisation complète
- alerte de sécurité

Ouvrir index.html dans un navigateur.
